# /input/ — External sources

READ-ONLY.

This layer holds external documents, data, or references that the system needs to consume — but that are not generated by the system and do not belong to the project's own context.

---

## What belongs here

- Source documents to analyze or transform
- Reference material from third parties
- Raw data to process
- Existing assets to build upon (a previous version, a competitor's output, a brief from a client)

## What does NOT belong here

- Business truth about your own project → that goes in `/context/`
- Rules for how to process this input → those go in `/specs/`
- Outputs derived from this input → those go in `/output/`

---

## How to use this layer

Drop files here at project start or whenever new source material arrives. Name them clearly so the agent knows what each one is. If there are many files, add a short `index.md` listing what each file contains and why it's relevant.

---

## Note on naming

Do not use a folder called `/docs/` at the repo root for this purpose. In this architecture, `docs` under `/output/` means generated documentation. `/input/` is the convention for what the system receives.
