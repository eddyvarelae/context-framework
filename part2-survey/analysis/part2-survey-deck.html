The headline

Strong demand, beginner cohort, one clear gap

Demand is real and unanimous
15 of 50 students responded and every one is interested — 12 firm "yes," 3 "maybe," zero "no." All 7 teams are represented.
They want the back end
Top requests are real backends & APIs (73%), databases (67%), and authentication (60%) — the "missing middle" behind any real product.
The gap = the opportunity
The skills they want most are exactly the ones they're least confident in. Backend, cloud & databases sit near-zero on self-rated skill.
Most are building hardware
4 of 7 teams are building physical/IoT products that need a device → cloud → app pipeline — the exact stack they're asking to learn.

Recommendation

Teach the missing middle

Demand, skill gaps and project needs all point the same way: the server / cloud / data layer between a front end and a device. A proposed three-track shape:

1 · Core

Highest demand, lowest skill. Everyone.
  • Real backends & APIs (73% want, 13% have)
  • Databases: modeling & querying (67% / 16%)
  • Authentication done right (60%)
  • Coding without the builder (60%)

2 · Cloud pipeline

Serves the 4 IoT teams directly.
  • Device / app → cloud → data flow
  • AWS basics: Lambda, API Gateway
  • DynamoDB & S3 for storage
  • Deploying a back end that stays up

3 · AI track

60%+ demand; level up the tooling.
  • The Claude API inside an app
  • Agents & tools / function calling
  • Browser copy-paste → Claude Code
  • MCP & CV/ML as electives
