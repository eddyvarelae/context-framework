# Building with AI — Part 2 (Advanced): interest & skills survey

A screening survey for the optional advanced session. Only interested students
fill it out; the first question gates the rest so the not-interested can submit
immediately.

Every skill question is grounded in what we can actually teach (from the real
project stack): React/Vite/TypeScript frontends, AWS serverless backends
(Lambda + API Gateway), DynamoDB, S3 uploads, Cognito auth, SES email, the
Anthropic API, MCP servers, Claude Code, Git/GitHub + CI/CD, Python, and
computer vision (YOLO).

Build it automatically with `create-part2-survey.gs` (see that file), or
recreate by hand from the spec below.

---

## Intro (form description)

> **Part 2 is optional and advanced.** Part 1 was about building with an AI
> builder. Part 2 goes underneath it: real backends and APIs, cloud and
> serverless (AWS), databases, authentication, and AI engineering (the Claude
> API, agents, MCP, tools like Claude Code).
>
> **Only fill this out if you're interested in the advanced session.** Be
> honest about your experience — "never done it" is a completely fine answer
> and actually helps us pitch the class at the right level. There are no wrong
> answers and this isn't graded.
